# 失落的深渊 · The Lost Abyss

Three.js + HTML/CSS 制作的 2.5D 像素风暗黑奇幻原型。包含职业选择舞台、可移动寻路交互的主城「灰烬庇护所」，以及第一关可战斗地下城「废弃圣堂」。

## 运行

在项目目录启动静态服务器：

```bash
cd /Users/bytedance/Documents/Dungeon
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 **http://127.0.0.1:8000/**。

也可以使用 VS Code / TRAE 的 Live Server。请通过 HTTP 打开；直接双击 `index.html` 会受到浏览器 ES Module 安全限制。需要支持 WebGL 2 的现代浏览器，推荐 Chrome、Edge 或新版 Safari。

无需 npm、构建步骤、API Key 或账户。Three.js 0.170.0 的 CDN 发行文件已保存到 `vendor/`，运行时不请求外网。

## 已实现

- **职业选择**：精灵弓箭手、铁匠战士，职业介绍与特性条，呼吸待机，镜头环绕查看。
- **切换动画**：当前角色淡出与黑雾 → 新角色淡入 → 4.4 秒代码关键帧展示 → 回到待机。连续点击会收敛到最后选择的职业。
- **精灵动作**：抬弓、拉弦、瞄准停顿、释放箭矢、收弓。
- **战士动作**：倒转战锤杵地、叉腰、捶胸致意、回到站姿。
- **攻击动作**：弓箭手拉弓放箭（远程抛射弹道），战士挥锤横扫（近战扇形判定），武器挂于手掌骨骼避免穿模。
- **地下圣堂**：阶梯石台、石柱、哥特尖拱、铁门、铁艺烛台、点光源、地面薄雾、浮尘和呼吸镜头。
- **主城**：等距箱庭、房屋与门窗、铁匠炉火、祭坛、药剂摊、枯树、训练木桩。支持 WASD、方向键、点击地面寻路、地标自动寻路和建筑碰撞。
- **第一关地下城「废弃圣堂」**：中殿列柱、双排长椅、碎石、祭坛圣焰、四盏烛台、铁门出口。四只「低语者」敌人会追击并近战攻击玩家。
- **战斗系统**：鼠标悬停索敌并显示脚底红圈，左键发动单次攻击；攻击时显示职业射程。弓箭手使用远程箭矢，战士使用近战扇形判定。命中会触发短硬直、分级击退、冲击环、碎片、爆闪与火花反馈。
- **职业大招**：弓箭手「月蚀箭雨」对锁定区域造成范围伤害并降下箭雨；战士「余烬震击」重砸地面释放火焰震波与余烬粒子。大招使用 `Q`，带独立冷却。
- **设施交互**：药剂购买与使用、武器锻造、训练伤害与一次性奖励、行囊、地标地图、操作指南。
- **完整主城委托**：接取告示 → 找回三簇余火 → 返回祭坛 → 点亮余火并领取一次性奖励。完成后深渊之门开启地下城。
- **自由视角**：拖拽旋转偏航/俯仰、滚轮缩放；低角 / 经典 / 平视三种预设与一键重置；城镇与地下城跟随玩家。
- **昼夜时间**：程序化天空穹顶随小时变化（夜→昏→昼），太阳/月亮光强、雾色、曝光联动；右上角时钟可暂停/继续，文本实时更新。
- **本地进度**：职业、金币、药剂、生命、强化等级、委托和训练奖励。带数据校验与上一份有效存档备份。
- **适配**：桌面与窄屏布局、触屏方向键、精细/经典像素切换、可选环境音、减少动态效果偏好。

“开始冒险”严格按需求只执行 `console.log`。进入主城请点击顶部 **灰烬庇护所**，或右下方 **先探索灰烬庇护所**。完成余火委托后，深渊之门开启第一关地下城。

## 项目结构

```text
index.html                 界面、SVG 图标、模块入口
style.css                  暗金哥特界面、响应式布局
main.js                    Three.js 世界、模型、动画、输入、寻路与交互
vendor/three.module.min.js  Three.js 0.170.0，本地 CDN 发行文件
vendor/THREE-LICENSE.txt    Three.js MIT 许可
PROJECT_STATE.md            当前交付范围与验收记录
```

`main.js` 中的主要入口：

- `CLASS_DATA`：职业文案、特性与移动速度。
- `createProceduralCharacter()`：共享层级骨架、装备、待机、行走、展示与攻击关键帧。
- `createSelectionWorld()` / `createTown()` / `createDungeon()`：三个程序化场景。
- `batchArchitecture()`：按材质合并静态建筑，减少绘制调用。
- `requestClass()` / `updateSelection()`：可连续输入的角色切换状态机。
- `pathfind()` / `updateMovement()`：A*、障碍膨胀、禁止穿角、移动与步态。
- `addPoi()`：注册主城地标、寻路终点和交互回调。
- `playerAttack()` / `doPlayerDamage()` / `spawnArrow()` / `damageEnemy()`：地下城战斗循环。
- `createEnemy()` / `updateDungeon()`：敌人 AI（追击带障碍滑行）、受击、血条 billboard。
- `updateDayNight()`：程序化天空穹顶、太阳/月亮光、雾色与曝光联动。
- `updateCamera()`：轨道相机（偏航/俯仰/缩放），跟随玩家。
- `persist()` / `validSave()`：本地进度及有效备份。

## 替换真实角色模型

导出的 `registerCharacterFactory(id, factory)` 与 `reloadCharacter(id)` 是模型接入接口，支持异步工厂。无需改动场景切换、职业 UI 或主城逻辑。

工厂返回：

```js
{
  root,                           // THREE.Group，脚底位于原点
  update(dt, elapsed, pose),       // pose.type: idle / walk / showcase / attack
  setOpacity(value),              // 0～1，统一处理所有网格的淡入淡出
  dispose()                       // 可选，释放该角色独占的资源
}
```

约定：

- Y 轴向上，面朝 +Z，脚底 `(0, 0, 0)`，角色整体高度约 2.7 世界单位。
- `pose.type === "walk"` 时提供 `pose.step`，由碰撞后的实际移动距离驱动。
- `pose.type === "showcase"` 时提供 `pose.time`，范围为 0～4.4 秒。
- `pose.type === "attack"` 时提供 `pose.time`，弓箭手约 0.85 秒（0.5 秒释放），战士约 0.8 秒（0.55 秒命中）。
- GLTF 模型可以在适配器中用 `AnimationMixer` 对应待机、行走、展示片段。
- 独立克隆角色材质，避免 `setOpacity()` 改到其他角色或场景。
- 工厂注册后调用 `await reloadCharacter('archer')`；替换应在待机时进行。

此版本未附带 GLTF 文件或外部动画资源。

## 存档与范围

存档在当前浏览器、当前站点的 `localStorage` 中，键名为 `lost-abyss-save-v1`。不同浏览器或不同端口不共享存档。无账号、无联网同步。损坏的存档会尝试恢复有效备份；无法恢复时使用临时进度并保留原数据。每次进入主城从广场入口开始，角色坐标不持久化。

这是职业展示、主城交互与第一关地下城战斗 MVP；职业数值用于介绍、移动、训练与地下城战斗演示。环境音为简单本地合成氛围音。验证结果见 `PROJECT_STATE.md`。
